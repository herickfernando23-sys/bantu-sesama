Tips pengambilan screenshot:

- Gunakan resolusi desktop full page jika memungkinkan.
- Tampilkan tanggal/jam browser saat perlu bukti pengujian.
- Untuk bukti status API, boleh tambah screenshot terminal/Postman.
- Hindari menampilkan data sensitif (token, email pribadi asli, API key).
